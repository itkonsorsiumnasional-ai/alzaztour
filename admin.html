Impor paket dari JSON

Tempel kode JSON atau pilih file .json. Bisa berupa satu paket, daftar paket, atau {"packages":[…]}. Yang wajib hanya name, dest, dan days. Anda bisa memeriksa hasilnya dulu sebelum disimpan.

Format JSON yang dikenali

  • departures: daftar tanggal berangkat, format 2026-12-02 atau 02/12/2026. Tambah * untuk high season.
  • daily: ["2026-11-01","2027-03-31"] kalau berangkat setiap hari.
  • itinerary: daftar hari, tiap hari [judul, isi, hotel].
  • image: nama file yang sudah ada di repo (mis. img/bali.jpg), atau data gambar base64.
  • flags: kode negara untuk bendera, mis. ["th","my"].
  • Nama kolom bahasa Indonesia juga dikenali: nama, tujuan, hari, harga, termasuk, syarat.
  • Kalau nama paket sudah ada, paket itu diganti.

Panduan singkat

        
    
          
  1. Tab Paket Wisata: klik Tambah paket baru atau Ubah pada kartu paket, isi formulir, lalu Simpan paket.
    2. 
          
  2. Punya banyak paket sekaligus? Pakai tab Impor / Ekspor JSON, tempel kode JSON, klik Baca JSON, cek hasilnya, lalu Impor.
    3. 
          
  3. Isi token sekali di tab GitHub, lalu klik Publish di bar bawah. Website ter-update dalam ±1 menit.
    4. 
          
  4. Foto dokumentasi: tab Dokumentasi → pilih foto → isi keterangan dan kategori → Tambahkan → Publish. Foto ikut terunggah otomatis.
    5. 
          
  5. Salah ubah? Klik Urungkan sebelum Publish. Paket bawaan bisa disembunyikan atau dikembalikan ke aslinya kapan saja.
    6. 
        

        
Keamanan

        
    
          
  • Kode akses di halaman ini hanya penghalang awal. Pengaman sebenarnya adalah token GitHub: tanpa token, tidak ada yang bisa mengubah website.
    • 
          
  • Gunakan token yang hanya untuk repo ini, masa berlaku pendek, dan jangan dibagikan.
    • 
          
  • Panel terkunci otomatis setelah 15 menit tanpa aktivitas, dan salah kode berkali-kali akan dikunci sementara.
    • 
          
  • Semua isi paket dibersihkan (tanda < > dibuang, gambar/warna/tanggal diperiksa) sebelum tampil di website.
